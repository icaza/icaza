## What I Build

### 🔎 [Ostium OSINT Browser](https://github.com/icaza/Ostium-Osint-Browser)

**An investigation workspace designed around privacy and user control.**

My main open-source project: a Windows browser built for Open-Source Intelligence (OSINT), digital research, and information analysis.

- 50+ integrated investigation tools.
- Web content extraction, link analysis, RSS monitoring, and geolocation mapping.
- Integrated Ollama client for AI-assisted analysis.
- Isolated browsing environments for separate investigative sessions.
- Privacy-oriented design, with local data management and no built-in telemetry.

[Explore the project →](https://github.com/icaza/Ostium-Osint-Browser)

### 🧠 IAnon — AI-Assisted Writing & Analysis

Exploring the relationship between language, writing patterns, and artificial intelligence.

IAnon combines text analysis with configurable transformations to help users examine and adapt their writing while maintaining control over the process.

The goal is not to hand everything over to AI, but to make it a tool the user can understand, direct, and refine.

Beyond my main projects, I experiment with ideas involving:
